# vagas.v8.ia.br

Página de vagas da V8 Aceleração. As candidaturas vão para a tabela `candidaturas` e os currículos para o bucket privado `curriculos` no Supabase.

**Abrir uma nova vaga:** adicione um item em `VAGAS` (`assets/vagas-data.js`), rode `python3 gerar.py` e publique. Cada vaga ganha seu endereço: `vagas.v8.ia.br/<slug>/`.
